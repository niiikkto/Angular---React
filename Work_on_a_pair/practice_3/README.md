# Практическая работа №3 — Менеджер задач (React Router + Context + localStorage)

## Описание проекта

Приложение **«Мои задачи»** — полноценный менеджер задач на React.

В этой практике закрепляются навыки:
- маршрутизации с помощью **React Router** (вложенные маршруты, `Outlet`, динамические параметры, search params);
- глобального состояния через **Context API**;
- сохранения данных в **localStorage** с помощью кастомного хука;
- организации кода (разделение на pages, components, context, hooks).

### Что умеет приложение

| Возможность | Описание |
|-------------|----------|
| Главная страница | Статистика: всего / выполнено / активно |
| Список задач | Добавление, фильтрация, отметка выполненными, удаление |
| Фильтры | «Все / Активные / Выполненные» через URL (`?filter=...`) |
| Страница задачи | Подробный просмотр, смена статуса, удаление |
| 404 | Страница «не найдено» |
| Сохранение | Все задачи автоматически сохраняются в `localStorage` |

- **React 19**

## Установка и запуск

1. Перейдите в папку проекта:

```bash
cd Work_on_a_pair/practice_3
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите dev-сервер:

```bash
npm run dev
```

4. Откройте в браузере адрес, который покажет Vite (обычно `http://localhost:5173`).

|---------|----------|
| `npm run build` | Сборка production-версии |
| `npm run preview` | Предпросмотр собранного приложения |
| `npm run lint` | Проверка кода с помощью oxlint |

## Маршруты

| Путь | Страница | Описание |
|------|----------|----------|
| `/` | `HomePage` | Главная + статистика |
| `/tasks` | `TasksPage` | Список задач |
| `/tasks?filter=active` | `TasksPage` | Только активные |
| `/tasks?filter=done` | `TasksPage` | Только выполненные |
| `/tasks/:taskId` | `TaskDetailsPage` | Детали конкретной задачи |
| `*` | `NotFoundPage` | 404 (без шапки) |

Все маршруты кроме 404 обёрнуты в `Layout` (шапка с навигацией).

## Основные концепции, которые реализованы

### 1. Вложенные маршруты + Outlet
```jsx
<Route element={<Layout />}>
  <Route index element={<HomePage />} />
  <Route path="tasks" element={<TasksPage />} />
  <Route path="tasks/:taskId" element={<TaskDetailsPage />} />
</Route>
```

### 2. Context API
`TasksProvider` хранит список задач и методы:
- `addTask(title, description)`
- `toggleTask(id)`
- `removeTask(id)`

Хук `useTasks()` позволяет получать данные в любом компоненте внутри провайдера.

### 3. Кастомный хук `useLocalStorage`
- Читает значение из `localStorage` только при первом рендере (lazy initializer)
- Автоматически сохраняет изменения
- Безопасно обрабатывает ошибки (битый JSON, приватный режим и т.д.)

### 4. Фильтры через search params
Фильтр хранится в URL (`?filter=active`), поэтому:
- можно делиться ссылкой с нужным фильтром;
- при обновлении страницы фильтр сохраняется;
- кнопка «Назад» в браузере работает корректно.

## Как пользоваться приложением

1. На главной странице видна статистика по задачам.
2. Перейдите во вкладку **«Задачи»**.
3. Добавьте новую задачу (название обязательно, описание — по желанию).
4. Отметьте задачу выполненной галочкой.
5. Кликните по названию задачи — откроется страница с подробностями.
6. Используйте фильтры «Все / Активные / Выполненные».
7. Данные сохраняются автоматически — после перезагрузки страницы задачи остаются.
