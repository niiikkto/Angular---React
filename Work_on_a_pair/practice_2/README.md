
# Практическая работа №2 — Todo List (компоненты + состояние)

## Описание проекта

Классическое приложение **Todo List** на React.

Цель работы — научиться:
- разбивать интерфейс на переиспользуемые компоненты;
- поднимать состояние вверх (lifting state up);
- передавать данные и колбэки через props;
- работать с локальным состоянием (`useState`);
- делать условный рендер и списки.

### Что умеет приложение

| Возможность              | Описание                                      |
|--------------------------|-----------------------------------------------|
| Добавление задачи        | Текст + выбор приоритета (низкий / средний / высокий) |
| Отметка выполненной      | Чекбокс                                       |
| Редактирование           | Двойной клик по тексту → режим редактирования |
| Удаление                 | Кнопка ✕                                      |
| Фильтры                  | Все / Активные / Выполненные + счётчики       |
| Визуальный приоритет     | Цветная полоска слева у каждой задачи         |
| Дата создания            | Отображается под текстом задачи               |

## Как устроено приложение

### Состояние живёт в `App.jsx`

```jsx
const [todos, setTodos] = useState([...]);   // список задач
const [filter, setFilter] = useState('all'); // текущий фильтр
```

Все операции (добавление, переключение, удаление, редактирование) выполняются через функции в `App`, а детям передаются только нужные колбэки.

### Компоненты и их ответственность

| Компонент     | Что делает                                      | Что получает через props          |
|---------------|--------------------------------------------------|-----------------------------------|
| `TodoForm`    | Форма + выбор приоритета                         | `onAdd`                           |
| `Filters`     | Кнопки фильтров и счётчики                       | `current`, `onChange`, `counts`   |
| `TodoList`    | Рендерит список `TodoItem` или «пусто»           | `todos`, `onToggle`, `onDelete`, `onEdit` |
| `TodoItem`    | Одна задача: чекбокс, текст, дата, редактирование | `todo`, `onToggle`, `onDelete`, `onEdit` |

### Редактирование задачи

- Двойной клик по тексту → появляется поле ввода.
- `Enter` или кнопка 💾 — сохранить.
- `Escape` или кнопка ✖️ — отменить.
- Состояние редактирования (`isEditing`, `editText`) хранится **локально** внутри `TodoItem`.

### Приоритет

При создании задачи выбирается один из трёх уровней. Цвет левой полоски:
- 🟢 низкий
- 🟠 средний
- 🔴 высокий

---

## Как пользоваться

1. Введите текст задачи и выберите приоритет → нажмите «Добавить».
2. Отметьте задачу выполненной галочкой.
3. Дважды кликните по тексту, чтобы отредактировать.
4. Переключайте фильтры «Все / Активные / Выполненные».
5. Удаляйте ненужные задачи кнопкой ✕.
