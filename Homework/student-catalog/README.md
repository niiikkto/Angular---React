# 🎓 Каталог студентов (Student Catalog)

Учебное одностраничное веб-приложение (SPA) на **React** и **Vite**, разработанное для отработки базовых концепций библиотеки: синтаксиса JSX, декомпозиции интерфейса на компоненты, передачи данных через `props`, условного рендеринга и работы со списками (`.map()`).

## ✨ Реализованный функционал

- **Блок сводной статистики (`StatCard`)** — автоматический расчёт общего количества студентов, среднего балла (GPA), минимального возраста и количества уникальных городов с отображением тематических иконок.
- **Адаптивная сетка карточек (`StudentList` & `StudentCard`)** — отображение информации о каждом студенте с автоматической подстройкой колонок под ширину экрана.
- **Генерация аватаров** — динамическая подгрузка аватаров с инициалами через сервис `ui-avatars.com`.
- **Система бейджей (`Badge`) и условный рендеринг** — цветовая индикация курса обучения и автоматическое присвоение значка `🏆 Отличник` студентам со средним баллом `>= 4.5`.
- **Рейтинг в звёздах** — визуализация среднего балла (GPA) с помощью символов `⭐` и `☆`.
- **Список компетенций (`SkillsList`)** — отдельный компонент для отображения стека технологий каждого студента.

## 🛠 Технологический стек

- **React 18+** (функциональные компоненты, JSX)
- **Vite** (сборка проекта и HMR dev-сервер)
- **JavaScript (ES6+)** (деструктуризация, методы массивов `.map()`, `.reduce()`, структура `Set`)
- **CSS3** (CSS Grid, Flexbox, инлайн-стили)
